# Agave

[Agave](https://github.com/anza-xyz/agave) is the upstream Solana validator implementation and the baseline implementation for this specification.

This page records the reference at reviewed Agave revision [`6dd9d387`](https://github.com/anza-xyz/agave/tree/6dd9d38771e46103b9680357a855804165612602). The matching specs revision is [`5342447`](https://github.com/solana-rpc/specs/tree/534244734fc0a249396ac3ac8448a38fa07c29c9). It is a navigation and source-reference aid. The normative request, response, and error contracts remain in the method and schema pages.

## Static review findings

This review traces each method from its generated RPC registration through the concrete handler and processor at the pinned revision. It checks request fields, commitment handling, principal result variants, and named method errors. It does not exercise a live validator, optional BigTable storage, account indexes, feature activation, or cluster-specific data.

- The 14 published contracts and 19 pending standard contracts accept the standard calls implemented by the pinned Agave handlers. Their current `agave: full` ratings are supported by this static review.
- The five pending extensions are not implemented by Agave. Three extend existing Agave methods and therefore rate the extension `Partial`; two add method names that Agave does not expose and rate `None`.
- The pinned `getTransaction` processor accepts an additive `minContextSlot` field and returns `MinContextSlotNotReached` when the selected commitment view is behind it. The current published page and PR #12 do not document this newer field. This is a specification coverage gap, not a failure of standard calls described by those pages.
- Source review proves code paths and declared wire types, not live conformance. A future dynamic suite should cover error payloads, optional storage fallbacks, feature-gated response members, and PubSub notification timing before treating this table as a complete behavioral certification.

## Scope

This repository specifies a representative and growing subset of Agave RPC. This page covers method pages published on the reviewed specs revision and method or extension pages in the linked draft PRs. A method absent from both lists is not an unsupported-method finding. The remaining public Agave RPC surface is being added one method per draft PR.
